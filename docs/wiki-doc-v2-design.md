# pi-harness · Wiki 文档页 v2 设计方案

## 问 pi 浮动助手（2026-10-19）

问 pi 默认以 420px 浮动面板打开，可拖动、调整尺寸和固定到右侧；固定时替换大纲，收起恢复大纲，浮动时大纲保持原布局。小于 900px 改为全宽覆盖，记住桌面布局选择。浅灰表面、白色输入框、系统无衬线字体和轻阴影沿用当前语雀参考，支持深色；发送／停止保留黑色圆形图标。顶部提供固定、新建、历史和收起，空状态展示实际模型、文档问答／结合知识库，以及「根据当前文档 + 可选项目／知识库进行分析」，不显示提问建议。

项目选择面板按现有 Workspace 分组选择一个项目／知识库，追加到当前 Markdown 的分析范围。每篇 Markdown 恢复自己的 chat，切换时清空追加选择，返回也不恢复；历史列表只显示当前文档的会话。Desktop 浮动模式为独立原生窗口，Web 保持页面内浮动。详见 `architecture-wiki.md`。


2026-10-19 最新视觉以 `ui-design.md` 顶部「语雀桌面参考」为准：系统无衬线字体，36px / 50.004px 标题、24px / 32px H2、20px / 28px H3、15px / 26.1px 正文（2026-10-20 页面实测；标题及强调文字 700，正文 0.12px 字间距；字体回退顺序见 ui-design.md），白色正文和大纲、浅灰文件栏、中性灰选中态。以下旧版尺寸与 MiSans、蓝色选中态说明被此规则替代；编辑与保存交互保持不变。

编辑补充：`/` 空查询显示六列图标网格（正文、H1–H6、列表、任务、链接、代码、引用、高亮等 19 项），输入搜索词后显示说明列表；顶部常用工具栏继续保留紧凑分组。最近使用最多三项，保存在本地偏好中。代码块使用白底细边框、行号、整块折叠、宽版按钮及右下角纵向尺寸调整；折叠不是语言语法级别的代码折叠。空段落提示为「输入 / 唤起更多」。

参考：用户提供的文档编辑器截图（细工具栏 + 信息标签 + 安静的表格；2026-10-19 走查统一标题字体与紧凑排版）。
定稿：**34a**，设计图见 `wiki-doc-v2-design.html`，可以切换默认、表格尺寸、代码块语言、更多插入、宽版五种状态。
本文保留正文排版与插入工具栏规范。外壳以 `ui-design.md` 第 7 节为准：独立文档窗口使用专用标题栏与正文目录与可浮动／固定的「问 pi」助手，选区先保存再回填原聊天；自动保存及 `/` 菜单继续沿用。

| 2 | 文档上方单独一条**细工具栏**，只放插入功能和宽度切换 |

## 2. 布局

独立文档窗口右栏默认显示目录；「问 pi」复用原聊天，展开时为 400px，可调宽和收起，小屏为覆盖面板。

```
┌ 标题栏：路径 / 文件名 · 保存状态 … 目录 搜索 改动 问 pi 关闭 ┐
├ 可选文件栏 250px ┬ 格式工具栏 44px            ┬ 问 pi / 目录 400px ┤
│ 搜索／目录树     │ 标题 / 信息标签 / 正文    │ 原聊天消息        │
│ 默认展开        │ 正文最宽 760px，居中*     │ 同一输入与附件    │
└─────────────────┴ 索引状态                  ┴───────────────────┘
```

| 状态 | 列宽 | 正文最宽 |
|---|---|---|
| 默认 | 文档区 / 目录 400px | 760px |
| 问 pi 展开 | 文档区 / 聊天 400px | 760px |
| 文件栏展开 | 250px / 自适应 / 按需聊天 | 760px |
| 宽版（↔） | 文档区加宽，可手动收起聊天 | 1000px |

文档区用 `--bg-elev`，文件栏使用 `--sidebar-bg`。文档区和工具栏设 `min-width: 0`，窄屏工具栏横向滚动。最近改动为覆盖抽屉，不挤压正文；刷新保留聊天展开状态。

\* 宽屏比例：正文与右侧目录作为一个组合，在文件栏之外的可用阅读区内居中，左右均分剩余空间；隐藏大纲或固定问 pi 后按实际剩余空间重新居中。正文仍保留阅读宽度上限，宽版（↔）模式同样居中，避免全屏时空白集中在右侧。

## 3. 顶栏

- 独立窗口使用专用文档标题栏，不再显示主应用顶栏、视图切换和底部状态栏；桌面端整条标题栏与面包屑均可拖动，交互控件为 `no-drag`。
- 面包屑写目录路径（灰色），后面是文件名（600 字重），再后面是保存状态：
  - 已保存：绿点 `--green`
  - 保存中…：黄点 `--yellow`
  - 保存失败 · 重试：红点 `--red`，文字可以点击
- 右侧依次为目录、搜索、最近改动、「问 pi」和关闭／系统窗口控制；窄屏收敛为图标。

## 4. 左栏 · 目录树

- 顶部：「搜索文件」入口，圆角 `--r-md`、`--bg-elev` 底，右侧显示 ⌘P（Windows/Linux 显示 Ctrl P）。
- **目录**前面用 ⌄（展开）或 ›（收起），15px，灰色。
- **文件**显示线框文件图标，文件／目录共享箭头占位和图标列。
- **选中的文件**：浅蓝高亮 `--accent-soft` 底 + 左侧 2px `--accent` 指示条，字重 600（与对话页任务选中态一致）。
- 悬停：`oklch(0.95 0.004 80)`。

## 5. 文档工具栏

高 44px，底部 1px 分隔线，内边距 0 14px。

```
[目录 链接] · [T  H2  H3] · [列表 待办 表格 图片 引用 日期] · [</>]    [编辑源码]  ↔
```

| 分组 | 按钮 | 提示（悬停时显示） | 点击后 |
|---|---|---|---|
| 导航 | 目录 | 插入目录 | 在标题下插入 `<!-- toc -->` 块 |
| | 文档链接 | 双链 · [[ | 在光标处插入 `[[` 并打开文档搜索 |
| 标题 | 正文 | 普通正文段落 | 当前段落改成正文 |
| | 标题 2 | 二级标题 · ## | 当前段落改成 H2 |
| | 标题 3 | 三级标题 · ### | 当前段落改成 H3 |
| 列表与插入 | 列表 | 列表 · - | 改成无序列表 |
| | 待办 | 待办 · [] | 改成待办 |
| | 表格 | 表格 | 弹出尺寸格（见 5.1） |
| | 图片 | 图片 · 也可以直接粘贴 | 打开文件选择 |
| | 引用 | 引用 · > | 改成引用 |
| | 日期 | 提及日期 · @ | 插入今天的日期 |
| 代码 | 代码块 | 代码块 · ``` | 弹出语言列表（见 5.2） |
| 右侧 | 编辑源码 | 源码编辑 / 渲染预览 | 切换源码视图（次级按钮） |
| | ↔ | 宽版阅读（隐藏两侧）/ 标准宽度 | 切换宽版 |

**按钮规格**
- 28 × 28px，圆角 `--r-sm`，没有边框；图标 16px。
- 图标：24 viewBox，线宽 1.6px，圆角线头，17px，颜色 `oklch(0.32 0.01 80)`。
- 悬停：`oklch(0.95 0.004 80)` 底。
- 打开或按下：`oklch(0.95 0.02 240)` 底，图标变成 `--accent`。
- 组内间距 4px；组与组之间是一条 1 × 14px 的浅线 `oklch(0.93 0.004 80)`。
- 不用字符画的图标（▦ ▨ ☑ 这类显示出来像花纹）。所有图标都用同一套线框 SVG。

### 5.1 表格尺寸格
- 弹出层在表格按钮下方，白底，1px 描边，圆角 `--r-md`，阴影 `0 14px 36px` 加 16% 透明度。
- 8 列 × 6 行的格子，每格 16px，间距 3px，圆角 3px。
- 鼠标移动时，从左上角到当前格的区域高亮：`oklch(0.93 0.03 240)` 底，`oklch(0.75 0.06 240)` 描边。
- 底部一行：「4 列 × 3 行」，右侧灰字「带表头」。
- 点击后插入表格，第一行是表头。键盘：方向键调整尺寸，↵ 插入。

### 5.2 代码块语言
- 宽 200px，顶部是「搜索语言…」输入框。
- 列表：自动识别（默认）、bash、python、ts、json、yaml、sql、mermaid。左边是等宽字体的语言名，右边是灰色说明。
- 选择 `mermaid` 时，插入后会渲染成图表，下方保留源码编辑。
- 直接按 ↵：用「自动识别」插入。

### 5.3 完整插入工具栏
40px 高，插入、撤销重做与清除、段落与字号、字体样式、颜色、段落格式、常用插入依次排列。宽度不足时右侧分组收进“更多”；内容块集中在插入菜单。宽度切换按钮保留在末尾，`/` 菜单继续可用。

## 6. 文档排版

| 元素 | 字体 | 字号 / 字重 / 行高 | 间距 |
|---|---|---|---|
| 标题 H1 | `--sans` | 34px / 600 / 1.25，字距 -0.01em | 文档顶部 44px |
| 信息标签 | `--sans` | 12px | 标题下方 14px，标签之间 8px |
| H2 | `--sans` | 22px / 600 / 1.4 | 上 28px，下 8px |
| H3 | `--sans` | 15px / 600 | 上 22px，下 8px |
| 正文、列表 | `--sans` | 14.5px / 400 / 1.6 | 列表项间距 2px，缩进 24px |
| 行内代码 | JetBrains Mono | 12.5px | 内边距 1px 5px，圆角 4px，底色 `oklch(0.955 0.004 80)` |
| 链接 | — | 继承正文 | `--accent`，下划线用浅蓝 `oklch(0.8 0.05 240)`，偏移 3px |
| 表格 | `--sans` | 13.5px / 1.6；表头 12.5px | 单元格内边距 6px 10px |

- 正文最宽 760px（宽版 1000px），左右留白 48px（窄屏 20px），顶部 40px，底部 120px。最新字体尺度以文末单行工具栏与正文层级规范为准。
- **信息标签**：圆角 6px，内边距 2px 8px，底色 `oklch(0.955 0.004 80)`。
  - 内容：日期（前面加日历图标）、阅读时间、#标签。
  - 后面跟灰字「N 篇引用本文」，为 0 时隐藏。
  - **不显示作者标签**。
- **表格**：
  - 灰底表头（`--bg-elev2`），灰字。
  - 保留细行列分隔线，文字列左对齐，状态列紧凑居中，Markdown 显式对齐优先。
  - 表格比正文宽时，在表格内部横向滚动。
- **空行提示**：光标所在的空段落显示灰字「输入 / 插入内容，或直接写」，14px，颜色 `oklch(0.7 0.005 80)`；开始输入后消失。

## 7. 编辑行为

- 只有编辑模式，文档打开后光标落在正文末尾。
- 停止输入 800ms 后自动保存；切换文件、关闭窗口、⌘S 时立即保存。保存状态显示在顶栏文件名后面。
- 选中文字时浮层仅显示“问 pi”；格式按钮统一在顶部，作用在保留的当前选区上。
- Markdown 快捷写法照常生效，比如行首输入 `## ` 就变成标题。
- 外部修改提示、草稿离开保护沿用现有逻辑。

## 8. 对话面板（沿用 19a）

- 默认显示当前文档目录；点击「问 pi」、文件引用或选区提问时替换为聊天，收起聊天恢复目录，保留窗口级选择；宽 400px，`--bg` 底，左边 1px 分隔线，刷新保留展开状态。
- 头部：「问 pi」、当前文档名、临时会话说明和 ✕；不再重复主窗口品牌、模型名或新对话按钮。
- 空状态：居中品牌区 + 2×2 快捷操作卡片（图标统一品牌色 `--accent`），放在靠近输入框的位置。
- 引用标签：浅蓝胶囊（`--accent-soft` 底 + `--accent` 字）。
- 发送按钮：实心 `--accent` 圆形。

## 9. 不再出现

- 阅读 / 编辑切换、⌘E、阅读模式下变灰的插入按钮。
- 正文内部重复的格式工具栏。
- 「@作者」标签。
- 文件名前的 ▢ 占位图标（使用文件／文件夹线框图标替代）。
- 带米色圆角底板的 PNG logo（界面内）。
- ▦ ▨ ☑ 这类字符图标。

## Wiki 单行工具栏与正文层级（2026-10-20）

Wiki 的插入与格式命令统一挂载在标题栏下的 40px 工具栏，按钮 28px、图标 16px。按容器实际宽度将右侧分组移入“更多”，不换行；插入菜单集中图片、表格、代码、高亮块、折叠块、链接卡片、文档链接、日期及目录。菜单支持方向键、Home/End、Esc 返回触发按钮，保留编辑选区。选区浮层只保留“问 pi”。源码与宽版入口保持原有行为，小记继续使用紧凑工具栏。

正文内容最大宽度 760px，宽版 1000px，容器另含左右各 48px 留白（窄屏 20px）；顶部留白 40px。沿用已确认字体，正文 15px/1.74、标题 36px/约 50px，段距 12px、列表缩进 24px、条目间距 4px。任务列表仅显示绿色复选框。日期与阅读时间为 12px 灰色辅助信息。文档属性默认折叠，按工作区和路径重新挂载，窄屏上下排列；展开、工具栏布局和大纲导航不调用保存或改写原文字节。

### 斜杠菜单分组（2026-10-20）

空查询保留最近使用，常用格式为两行六列图标；基础元素使用双列具名卡片，内容块使用单列名称与说明。面板宽 360px，最大宽度受视口约束，内容区独立滚动；保留搜索、方向键、Enter 插入与 Esc 关闭。高亮、建议、警告使用语义色及不同图标，避免相同方框；不增加尚未实现的功能。小记菜单不变。
