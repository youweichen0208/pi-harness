# pi-harness · Wiki 文档页 v2 设计方案

参考：用户提供的文档编辑器截图（细工具栏 + 衬线大标题 + 信息标签 + 安静的表格）。
定稿：**34a**，设计图见 `wiki-doc-v2-design.html`，可以切换默认、表格尺寸、代码块语言、更多插入、宽版五种状态。
本文保留正文排版与插入工具栏规范。外壳以 `ui-design.md` 第 7 节为准：文档弹窗取代模式切换与独立对话面板，选区先保存再回填右侧原聊天；自动保存及 `/` 菜单继续沿用。

---

## 1. 已确认的决定

| # | 决定 |
|---|---|
| 1 | **只有编辑模式**：打开文档即可编辑，没有阅读/编辑切换，也没有 ⌘E |
| 2 | 文档上方单独一条**细工具栏**，只放插入功能和宽度切换 |
| 3 | 插入功能和 `/` 菜单是**同一份列表**：全部 11 项直接显示在工具栏，不再收进更多菜单 |
| 4 | **表格**弹出尺寸格，**代码块**弹出语言列表 |
| 5 | 标题用**衬线字体**，正文用无衬线字体，字号比 v1 整体小一档 |
| 6 | **去掉 AI 味**：文件／文件夹使用中性线框图标，logo 没有底板；当前文件用浅蓝高亮 + 左侧指示条（与对话页选中态一致） |
| 7 | 不显示页签按钮（「正文 ⌄」）和作者标签（「@Adam」） |

## 2. 布局

桌面弹窗宽 92vw（最大 1440px）、高 90dvh，小屏全屏；右侧 Agent Chat 复用原聊天，默认 400px，可调宽和收起。

```
┌ 顶栏：文件名 · 保存状态 …………… 最近改动  对话  放大／还原  关闭 ┐
├ 可选文件栏 250px ┬ 格式工具栏 44px            ┬ Agent Chat 400px ┤
│ 搜索／目录树     │ 标题 / 信息标签 / 正文    │ 原聊天消息       │
│ 默认收起        │ 正文最宽 760px，居中      │ 同一输入与附件   │
└─────────────────┴ 索引状态                  ┴──────────────────┘
```

| 状态 | 列宽 | 正文最宽 |
|---|---|---|
| 默认 | 文档区 / 聊天 400px | 760px |
| 文件栏展开 | 250px / 自适应 / 聊天 400px | 760px |
| 宽版（↔） | 文档区加宽，可手动收起聊天 | 1000px |

文档区用 `--bg-elev`，文件栏使用 `--sidebar-bg`。文档区和工具栏设 `min-width: 0`，窄屏工具栏横向滚动。放大仅改变弹窗尺寸，与正文宽版独立。

## 3. 顶栏

- 文档弹窗顶栏显示文件名、保存状态、放大／还原与关闭。
- 面包屑写目录路径（灰色），后面是文件名（600 字重），再后面是保存状态：
  - 已保存：绿点 `--green`
  - 保存中…：黄点 `--yellow`
  - 保存失败 · 重试：红点 `--red`，文字可以点击
- 右侧：「最近改动」，以及「放大 / 关闭」。

## 4. 左栏 · 目录树

- 顶部：「搜索文件」入口，圆角 `--r-md`、`--bg-elev` 底，右侧显示 ⌘P（Windows/Linux 显示 Ctrl P）。
- **目录**前面用 ⌄（展开）或 ›（收起），15px，灰色。
- **文件**显示线框文件图标，文件／目录共享箭头占位和图标列。
- **选中的文件**：浅蓝高亮 `--accent-soft` 底 + 左侧 2px `--accent` 指示条，字重 600（与对话页任务选中态一致）。
- 悬停：`oklch(0.95 0.004 80)`。

## 5. 文档工具栏

高 44px，底部 1px 分隔线，内边距 0 14px。

```
[目录 链接] · [T  H2  H3] · [列表 待办 表格 图片 引用 日期] · [</>]    [编辑源码胶囊]  ↔
```

| 分组 | 按钮 | 提示（悬停时显示） | 点击后 |
|---|---|---|---|
| 导航 | 目录 | 插入目录 | 在标题下插入 `<!-- toc -->` 块 |
| | 文档链接 | 双链 · [[ | 在光标处插入 `[[` 并打开文档搜索 |
| 标题 | 正文 | 普通正文段落 | 当前段落改成正文 |
| | 标题 2 | 二级标题 · ## | 当前段落改成 H2 |
| | 标题 3 | 三级标题 · ### | 当前段落改成 H3 |
| 列表与插入 | 列表 | 列表 · - | 改成无序列表 |
| | 待办 | 待办 · [] | 改成待办 |
| | 表格 | 表格 | 弹出尺寸格（见 5.1） |
| | 图片 | 图片 · 也可以直接粘贴 | 打开文件选择 |
| | 引用 | 引用 · > | 改成引用 |
| | 日期 | 提及日期 · @ | 插入今天的日期 |
| 代码 | 代码块 | 代码块 · ``` | 弹出语言列表（见 5.2） |
| 右侧 | 编辑源码 | 源码编辑 / 渲染预览 | 切换源码视图（胶囊按钮） |
| | ↔ | 宽版阅读（隐藏两侧）/ 标准宽度 | 切换宽版 |

**按钮规格**
- 30 × 30px，圆角 `--r-sm`，没有边框。
- 图标：24 viewBox，线宽 1.6px，圆角线头，17px，颜色 `oklch(0.32 0.01 80)`。
- 悬停：`oklch(0.95 0.004 80)` 底。
- 打开或按下：`oklch(0.95 0.02 240)` 底，图标变成 `--accent`。
- 组内间距 4px；组与组之间是一条 1 × 14px 的浅线 `oklch(0.93 0.004 80)`。
- 不用字符画的图标（▦ ▨ ☑ 这类显示出来像花纹）。所有图标都用同一套线框 SVG。

### 5.1 表格尺寸格
- 弹出层在表格按钮下方，白底，1px 描边，圆角 `--r-md`，阴影 `0 14px 36px` 加 16% 透明度。
- 8 列 × 6 行的格子，每格 16px，间距 3px，圆角 3px。
- 鼠标移动时，从左上角到当前格的区域高亮：`oklch(0.93 0.03 240)` 底，`oklch(0.75 0.06 240)` 描边。
- 底部一行：「4 列 × 3 行」，右侧灰字「带表头」。
- 点击后插入表格，第一行是表头。键盘：方向键调整尺寸，↵ 插入。

### 5.2 代码块语言
- 宽 200px，顶部是「搜索语言…」输入框。
- 列表：自动识别（默认）、bash、python、ts、json、yaml、sql、mermaid。左边是等宽字体的语言名，右边是灰色说明。
- 选择 `mermaid` 时，插入后会渲染成图表，下方保留源码编辑。
- 直接按 ↵：用「自动识别」插入。

### 5.3 完整插入工具栏
按斜杠菜单顺序直接显示：正文、标题 2、标题 3、列表、表格、图片、任务列表、引用、代码块、文档链接、提及日期。悬停显示名称、用途及快捷写法；H2/H3 使用可区分级别的图标。宽度不足时工具栏横向滚动，不撑宽页面；宽度切换按钮保留在末尾。`/` 菜单继续可用。

## 6. 文档排版

| 元素 | 字体 | 字号 / 字重 / 行高 | 间距 |
|---|---|---|---|
| 标题 H1 | Source Serif 4 + Noto Serif SC | 34px / 500 / 1.25，字距 -0.01em | 文档顶部 44px |
| 信息标签 | IBM Plex Sans | 12px | 标题下方 14px，标签之间 8px |
| H2 | Source Serif 4 + Noto Serif SC | 22px / 500 / 1.4 | 上 36px，下 8px |
| H3 | IBM Plex Sans | 15px / 600 | 上 28px，下 8px |
| 正文、列表 | IBM Plex Sans | 14.5px / 400 / 1.8 | 列表项间距 4px，缩进 24px |
| 行内代码 | JetBrains Mono | 12.5px | 内边距 1px 5px，圆角 4px，底色 `oklch(0.955 0.004 80)` |
| 链接 | — | 继承正文 | `--accent`，下划线用浅蓝 `oklch(0.8 0.05 240)`，偏移 3px |
| 表格 | IBM Plex Sans | 13.5px / 1.6；表头 12.5px | 单元格内边距 8px 14px |

- 正文最宽 760px（宽版 1000px），左右留白 64px，底部 72px。
- **信息标签**：圆角 6px，内边距 2px 8px，底色 `oklch(0.955 0.004 80)`。
  - 内容：日期（前面加日历图标）、阅读时间、#标签。
  - 后面跟灰字「N 篇引用本文」，为 0 时隐藏。
  - **不显示作者标签**。
- **表格**：
  - 灰底表头（`--bg-elev2`），灰字。
  - 仅保留行分隔线：单元格无纵向边框，只有 1px `--border-soft` 的横向行线（表头行去掉顶部线）。
  - 表格比正文宽时，在表格内部横向滚动。
- **空行提示**：光标所在的空段落显示灰字「输入 / 插入内容，或直接写」，14px，颜色 `oklch(0.7 0.005 80)`；开始输入后消失。

## 7. 编辑行为

- 只有编辑模式，文档打开后光标落在正文末尾。
- 停止输入 800ms 后自动保存；切换文件、关闭窗口、⌘S 时立即保存。保存状态显示在顶栏文件名后面。
- 选中文字时，在选区上方弹出浮动格式条（见「Wiki 编辑态」文档），工具栏按钮作用在当前段落或选区上。
- Markdown 快捷写法照常生效，比如行首输入 `## ` 就变成标题。
- 外部修改提示、草稿离开保护沿用现有逻辑。

## 8. 对话面板（沿用 19a）

- 宽 400px，`--bg` 底，左边 1px 分隔线。
- 头部：无底板 logo、对话、模型名（灰色）、新对话、✕。
- 空状态：居中品牌区 + 2×2 快捷操作卡片（图标统一品牌色 `--accent`），放在靠近输入框的位置。
- 引用标签：浅蓝胶囊（`--accent-soft` 底 + `--accent` 字）。
- 发送按钮：实心 `--accent` 圆形。

## 9. 不再出现

- 阅读 / 编辑切换、⌘E、阅读模式下变灰的插入按钮。
- 「正文 ⌄」页签按钮。
- 「@作者」标签。
- 文件名前的 ▢ 占位图标（使用文件／文件夹线框图标替代）。
- 带米色圆角底板的 PNG logo（界面内）。
- ▦ ▨ ☑ 这类字符图标。
