# 格式刷：整块替换、正文与标题双向复制、采样状态留在编辑器

格式刷在 v1.2.0 的工具栏重构中被整块删除（`6fc7ab1`），i18n 文案一并清空，只有 release note 记了一句「移除格式刷和清除格式按钮」。和 ADR-0007 的表格结构编辑是同一个剧本：能力消失、文档没说、没人发现。这次恢复把它写成规则。

三条规则看起来都可以「顺手改掉」，所以必须写下来：

**整块替换，不是合并。** 格式刷是「把这段变成那段的样子」，不是「往这段上贴几个属性」。源段落没有 `text-align` 时，目标的 `text-align` 会被**移除**而不是保留。合并语义下用户会看到「刷了但没刷全」；替换语义与 Word / 语雀一致。这也让「清除格式」和「格式刷」共用同一条块级替换路径。

**正文与标题双向复制。** 正文可以刷成标题，标题也可以刷回正文，标题级别之间可以互换。多块选区逐块复制类型；列表和表格单元格保留结构，仅复制样式。此规则取代最初的“只升级、不跨块传播”限制。

**普通正文可作为重置来源。** 有文字但没有额外样式仍是有效采样，可清除目标格式。空块仍禁用采样。替换时同时剥除目标的粗体、斜体、下划线、删除线和高亮语义标签，避免残留格式。

**采样结果是两个域，不是一条扁平字符串。** `cleanStyle` 返回 `font-size; color; text-align; line-height` 混在一起的一串；格式刷必须分别把行内属性应用到文字、块属性应用到块。这需要拆分的纯逻辑，因此有 `web/src/format-painter.ts`：`splitStyle`、`mergeBlockFormat`、`isUpgrade`、`diffAgainstBaseline`，零 DOM，由 `tests/unit/format-painter.test.ts` 直接测试。DOM 采样（`getComputedStyle`）留在 `RichMarkdownEditor`，用 E2E 覆盖。

**采样必须减去基线。** `getComputedStyle` 报告每个属性的**解析值**，普通段落也「拥有」字号、颜色和 `font-style: normal`。原样应用会把用户从未设置过的格式印到块上，并且会存进文档。采样时先对一个游离的普通段落取基线，只保留有差异的声明。

## Considered Options

-   **合并语义（只覆盖采样到的属性）**：改动更小，但源段落没有某属性时无法复位目标，表现为「刷了但没刷全」——被否。
-   **多块选区逐块传播块类型**：行为更「聪明」且实现更简单，但选中多段再点格式刷会静默产生大片标题，且 `insertHTML` 只进一条原生撤销——初版否决，现按用户要求支持。
-   **块类型双向传播**：现已采用；仅限正文和标题，不替换列表或单元格容器。
-   **把采样状态放进 `RichCommands`**：能继续复用现有单测，但会把那条干净的协议测试（`capture → restore → execute` 顺序断言）变成 DOM 测试——被否。
-   **采样时决定行内/块模式**：用户得退出重进才能在文字和段落之间切换；持续模式下无法连续刷不同类型目标——被否。
-   **扩展 `cleanStyle` 白名单**：能让格式刷支持 `letter-spacing`、`margin` 等，但白名单一扩，`rich-markdown.tsx` 的 `filter`、`readRichDocument` 的剔除和 Markdown 往返都要同步核对，漏一处就是「编辑器显示的和存下来的不一样」——被否。格式刷只承诺可持久化子集。

## Consequences

-   **`cleanStyle` 是格式刷的能力边界。** 往白名单里加属性等于扩大格式刷的承诺，必须同时核对序列化往返（`docs/architecture-notes.md` 已记录这层换算）。
-   **持续模式（双击）需要键盘退出路径。** Esc 必须解除，否则用户会被困在一个看不见的状态里。
-   **采样位置无文字时按钮置灰并给出原因**，不进入模式。ADR-0007 已经记录过一次教训：静默失败是「以为坏了」的第二来源。
-   **`clear` 是两段式**：先用原生 `removeFormat` 清行内（浏览器优化过，手动剥行内更容易漏 `<mark>`、`<u>`、嵌套 span），再手动剥块级 style。目标块必须在原生命令执行**之前**解析，因为 `removeFormat` 会重写选区。
-   **回归**：`tests/unit/format-painter.test.ts` 守护三条纯逻辑规则；`tests/format-painter-test.mjs` 守护真实行为（arm/disarm、Esc、双向类型复制、替换而非合并、多块传播、普通正文重置与重新打开、清除、置灰原因）。
