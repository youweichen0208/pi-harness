# 知识库窗口与普通单文件弹窗的聊天归属

已接受并实施。完整 Wiki 从左侧「知识库」入口进入：单独配置的一个本地文件夹就是一个知识库，不依赖 Workspace 分组，沿用独立窗口和每篇文档独立的 Wiki 聊天历史。普通模式中所有 Markdown 打开入口统一进入单文件编辑弹窗，弹窗复用主聊天并引用当前文件，不创建独立文档聊天；Wiki 内部文档链接继续在 Wiki 中导航。

同一文档通过两个入口打开时，聊天归属有意不同：知识库用于持续阅读与文档讨论，普通弹窗用于当前编码对话中的文件修改。选择共享主聊天，避免单文件查看打断当前任务上下文；选择保留 Wiki 独立历史，避免知识库讨论混入编码会话。本文调整 ADR-0003 的 Wiki 入口范围，保留其独立窗口决策。首次进入选择文件夹，后续恢复上次文档，更换目录不移动文件或删除历史。单文件弹窗的自动引用跟随当前文件，关闭时移除；发送前保存并冻结快照，冲突阻止发送。关闭弹窗只把聊天展示移回主界面，正在执行的任务继续，未保存文档仍受保存保护。
