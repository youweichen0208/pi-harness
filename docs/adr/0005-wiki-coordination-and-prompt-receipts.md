# Wiki 切换协调与发送回执

2026-10-23，已接受。Wiki 切换、关闭与发送采用先到先执行的独立协调 module，React adapter 连接编辑器、传输与窗口；保留现有自动保存 module。普通聊天与 Wiki 共用持久化发送回执，选择重连查询和重复请求拦截，而不是断线后重发；SDK 接收与文件落盘无法原子提交，崩溃窗口必须保留 unknown，不能声称任务完成或 exactly-once。

澄清历史 ADR：ADR-0002 与 ADR-0003 中的「临时 Wiki 会话」及退出删除历史已被现有按文档持久化对话取代；独立窗口决策继续有效。本次保持按文档恢复历史、退出只回收运行实例，既不恢复临时历史，也不改变原生 SDK 队列的重启语义。具体生命周期与保留期见 `architecture-wiki.md` 和 `architecture-core.md`。
