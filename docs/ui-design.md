# 工作区界面规范（当前状态）

> 本文只描述**现在应该是什么样**。历史版本和被替代的规则移到 `docs/history/ui-design-changelog.md`。
> 修改界面时先改本文，再改代码；本文与代码冲突时，以本文为准，并修正代码。

---

主界面的视觉与布局以 v1.3.1 为基准；数据库、Wiki 文档弹窗及内置扩展管理保留当前功能和交互，统一使用本规范的视觉令牌。Workspace 创建位于左栏，新对话输入框位于底部；不使用居中首页、过程摘要或右栏页签。

## 1. 设计令牌

所有颜色和圆角只能通过 CSS 变量使用，组件里不写十六进制颜色（终端 ANSI 调色板和第三方渲染器配置除外，见 1.4）。

### 1.1 颜色

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#2F7AAE` | `#5BA3D6` | 选中状态、链接、开关、可以点的发送按钮、当前对话圆点、选中文件左边的竖条 |
| `--accent-soft` | `#EAF2F8` | `#203E52` | 开关打开时的底色（如「π 对话」按钮） |
| `--green` / `--green-soft` | `#3E9B5F` / `#E6F4EA` | `#79C68E` / `#243C2B` | 完成、成功 ✓、diff 新增行 |
| `--red` / `--red-soft` | `#C9483A` / `#FBE9E7` | `#EF9689` / `#452B29` | 失败、中断 ✗、diff 删除行、危险操作 |
| `--yellow` | `#F2BC4E` | `#EDC765` | 进行中的圆点（左栏会话运行点用更深的 `--progress-text` 加 `--progress-soft` 光晕，保证 6px 圆点在暖白底上可见） |
| `--yellow-fg` / `--yellow-bg` | `#8A5A00` / `#FDF1D6` | `#EDC765` / `#463C22` | 改动数、待发标签、「工作中」文字 |
| `--bg` | `#FBF9F6` | `#1C1C1B` | 窗口背景 |
| `--bubble-bg` | `#F1EEEA` | `#33322E` | 用户消息气泡 |
| `--output-bg` | `oklch(0.97 0.003 80)` | `#292926` | 命令输出、代码块 |

**规则**
- 一种颜色只有一个含义：蓝色表示选中或链接，绿色表示成功，红色表示失败，黄色表示有改动或进行中。
- 界面不使用紫色。珊瑚色 `#EE8C7C` 只出现在图标和等待指示器的方块里。
- 同一个改动数只显示在两处：顶栏 Git 后面和目录树里，用黄色。文件栏标题里的「改动 N」用中性灰。
- 每个变量只定义一次：浅色在 `:root`，深色在 `:root[data-appearance="dark"]`，不在后面重复覆盖。

### 1.2 圆角

| 变量 | 值 | 用于 |
|---|---|---|
| `--r-sm` | 6px | 按钮、图标按钮、列表项、标签 |
| `--r-md` | 8px | 输入框、卡片、代码块、命令组 |
| `--r-lg` | 12px | 弹窗、设置窗口 |

圆点状态指示使用 50%；开关轨道使用 `--r-switch`，等待方块使用 `--r-waiting`（1.5px，见 4.4）。词级 diff 高亮使用 `--r-diff-word`（2px，内容专用）。其余圆角使用上表三个令牌；`0` 用于直角，`inherit` 只用于继承父元素圆角。

### 1.3 字体
- 界面和正文用 IBM Plex Sans，中文优先用本地 UI SC（Noto Sans SC 子集，400/500/600）；生僻字回落到 PingFang SC／Microsoft YaHei。子集包含 GB2312 一级字和前端源码中的汉字、标点。
- 命令、路径、版本号、代码用本地 JetBrains Mono，关闭连字；依次回落到 Cascadia Mono、SF Mono、Menlo、Consolas。
- 正文 13–13.5px，行高 1.7；辅助文字 12px；状态栏 11px。

### 1.4 允许写死颜色的地方
- 终端 ANSI 调色板（`--term-*`，光标使用 `--accent`）。
- Mermaid 等第三方渲染器配置读取 CSS 变量。独立代码配色（`--file-code-*`、`--wiki-code-*`、`.hljs-*`）可以定义内容色板，关键字使用蓝色系。
- 文字高亮色板（`remark-text-highlight` / `.fp-highlight-*`）。这是用户可选的内容颜色，不属于界面颜色。
- 系统关闭按钮悬停红色（`.desktop-window-close:hover`）。深色浮层及阴影统一读取根变量。
- 深色命令输出中的 Git 状态使用 `--out-green`、`--out-yellow`、`--out-red`，与界面状态色分开。

`npm run check:design` 扫描 `web/src` 下全部 `.css`、`.ts`、`.tsx`，禁止色板及上述例外之外的十六进制颜色、RGB/HSL、颜色名和紫色 OKLCH；非令牌圆角报错并给出行号。颜色名只检查样式值，避免误报文案、路径和标识符。透明色与 `currentColor` 可用。图片转码的白底和文档高亮序列化色板属于内容处理，检查只豁免对应文件中的指定声明。`npm test` 先运行此检查。根色板只允许根选择器中的变量声明，不能通过带 `data-appearance` 的组件规则绕过检查。

---

Windows 浅色界面在 React 渲染前设置 data-platform，正文字号按原基准增加 0.5px，次要文字使用 Windows 专用根令牌。浅色非终端滚动区默认隐藏滑块，悬停显示 8px 轨道中的 4px 滑块；拖动颜色加深。xterm 与深色模式沿用原样式。Electron 启动背景与暖白窗口一致。

## 2. 图标与品牌
- 侧栏 logo 24px，顶栏和 pi 头像 18px，统一使用 `1a-flat.svg`，不加底板。
- favicon 用 32px PNG，Apple touch icon 用 180px PNG。
- 产品界面的 emoji 图标统一改为 16px、stroke-width 1.5、currentColor 的线条 SVG；用户消息和文档原文不替换。

## 3. 布局

### Workspace 项目分组（#53）

左栏品牌下只显示 Workspace 切换器，不再显示“全部项目”或顶部“新对话”按钮。切换器是自定义弹出菜单（`WorkspaceSwitcher.tsx`，设计 2a–2c），不用原生下拉框：有选中项时显示首字头像与名称；菜单列出全部 Workspace（当前项打勾，其余显示项目数），其后是“新建 Workspace”（菜单内切换为名称表单）和“管理 Workspace…”（展开改名、加入当前项目、删除的管理面板）。头像颜色取 logo 三色（`--workspace-swatch-*`，无状态含义），按 Workspace ID 固定，不随排序或改名变化。菜单支持 ↑↓ 移动、Esc 关闭（新建表单中 Esc 先返回列表）、点击外部关闭。首次没有 Workspace 时切换器显示虚线“未选择 Workspace”，展开即为创建表单（2b）；其下显示“开始使用”三步清单（侧边栏空状态 1a）：① 创建 Workspace（内联名称输入与主按钮）② 添加项目 ③ 开始第一个会话，后两步只作预告、置灰；两处创建共用同一名称草稿。不展示旧最近目录或历史会话。禁用按钮用中性实色底而非半透明，保证可读。不删除磁盘目录、历史文件或服务端最近记录。创建分组后从空列表开始，用户手动添加项目。切换器只列出已有分组，优先恢复上次选择，选择失效时回到第一个分组；删除最后一个分组后恢复创建空态。

选择分组只筛选项目列表，不切换当前对话或 Agent 工作目录。当前项目不在分组时，显示“当前对话在此分组外”和“加入当前项目”按钮。添加项目通过目录选择器登记目录，不切换会话；点击项目仍走原有项目切换和未保存编辑保护。项目菜单支持从当前分组移除，当前项目菜单保留新对话操作；键盘新对话仍沿用当前项目。管理表单支持创建、重命名和二次确认删除分组，同一项目可属于多个分组。搜索仅查当前分组，空分组和无搜索结果显示明确空态。

保存期间禁用重复操作，失败保留编辑内容并显示错误；多窗口发生过期修改时刷新分组并要求用户重试。移动端管理操作保留左栏抽屉。原有会话、目录和 Agent 配置不随分组改变。

- 左栏 264px，可以拖动调整宽度和收起；右栏 272px，可以拖动调整宽度和收起。
- 对话内容和输入框宽度用 `--chat-max`：`clamp(780px, 48vw, 1040px)`，居中；笔记本保持 780px，大屏和全屏按比例加宽。
- 顶栏 44px，用下划线页签，当前页签只用加粗与蓝色下划线，不加底色（3a）；不可用的页签（如非 Git 仓库时的 Git）用 `--text-faint` 实色文字，不降低透明度。
- 数据库、节点、后台任务和插件保留直接入口；导航空间不足时横向滚动，左右侧栏按钮保持可点击。
- 状态栏 26px，显示连接状态 · 版本 · 分支 · 路径，不显示消息数。
- 宽度 ≤1100px 时，文件栏变成抽屉；≤768px 时，用移动端抽屉。

### 流畅界面（Web / Desktop 共用）

保留暖色底、蓝色操作强调和 pi 图标，沿用正文及代码字体。导航使用较厚的半透明材质，正文保持实色；弹窗、菜单使用更轻的浮层与统一阴影。标题以字重和微调字距建立层级，辅助标签保持清晰对比。顶栏仍为 44px，不改变 Electron 原生窗口按钮避让和可拖动区域。

按钮按下立即反馈，不等待请求完成；键盘焦点使用明确轮廓。移动端侧栏和窄屏文件抽屉使用可中断、携带当前速度的临界阻尼弹簧，进出沿同一路径。抽屉顶部专用拖动区支持指针捕获、速度投射和边界阻尼，正文滚动不被手势接管；关闭按钮和 Escape 均可关闭，隐藏抽屉不可获得焦点。宽屏面板宽度拖动保持 1:1，支持取消和键盘方向键调整。

减少动态效果时抽屉直接到位、浮层静态显示；减少透明度或提高对比度时使用实色背景和清晰边框。动画仅改变 transform/opacity，不给文本流添加入场位移，不循环播放装饰动画。

## 4. 对话流

通知：同一对话、级别和正文完全相同的可见通知合并为一条，以「×N」显示出现次数；不同对话的通知独立。重复信息通知刷新自动关闭计时，警告与错误保留到手动关闭。

### 4.1 消息
- 用户消息：靠右，`--bubble-bg`，圆角 8px，最宽 75%；时间放在气泡下方右对齐。内容完全相同、中间没有回复的连续用户消息只显示一次，时间旁标「已重发 N 次」（N 为多发的次数），其余保留定位锚点（3a）。
- pi 回复：一轮只有一行头部（18px logo · pi · 时间，时间紧跟 pi），模型名放在时间的悬停说明；正文不加气泡，和过程列表左对齐在同一列。
- system 消息是系统提示词快照，显示为居中分隔线「已加载系统提示 · 时间」，不作为聊天行（3a）。
- 过程说明：工具调用前后的短句（少于 40 字，说的是下一步要检查、读取或修改什么），用 12.5px 灰字。结论和要点保持正文样式。
- 长历史摘要每组保持单行，并沿用正常消息流的形状：用户摘要是靠右的单行气泡 + 时间；pi 摘要是 logo · pi · 时间 · 灰色预览；system 摘要同样是分隔线。用户摘要不显示附件原文（`<file …>` 包装）：技能显示为 `/名称` 蓝色等宽小标签，问题文字居中省略，附件显示为带回形针的文件名标签（多个时「+N」），重复发送在气泡下方与时间并列「已重发 N 次」；用户摘要气泡显示完整问题（最多 4 行）和全部附件名。被折叠的 pi 回复与随后展开的同一轮回复共用一个头像和名称。没有正文、思考、工具或错误的空回复（如中断的重试）在折叠区和完整视图都不显示，也不打断重复问题的合并。工具次数、思考和附件统计放在悬停说明，不再单独占一行；没有正文时用统计作为摘要。整行可点击或键盘展开，完整内容与搜索定位保留。
- 长历史的折叠摘要也参与惰性窗口化，首次加载先用等高占位；视口附近才挂载摘要。占位保留消息定位，搜索、展开与问题跳转仍可恢复完整内容。

- 对话里的 Markdown 标题末尾的括号说明（如「(不用你回答)」）显示为同行灰色小字副标题；紧贴在标题上方的分割线不显示，其余分割线为 1px 浅色。
- 顶栏会话标题去掉「skill:」前缀（显示「grill-with-docs · 问题」）；空间不足时分支标签和项目名先收缩，标题优先保留。

### 4.2 过程列表与命令组（3a / 27a / 29a）
- 两段正文之间的思考、bash、read、grep 合成一个带细边框的过程列表，每项一行、行间细分隔线，不再混用灰底单行、卡片和独立卡片。跨消息合并：只含这些步骤的后续消息并入上一组；下一条回复开头的思考/步骤也接在上一组末尾，其正文另起。编辑、其他工具、错误/中断消息和历史折叠边界会结束列表。
- 思考用时满 60 秒改写为「1m 17s」，满 1 小时为「1h 2m」（思考行、工具组标题、右栏步骤一致）。
- 执行步骤文案统一英文（中文界面也一样）：「Thought for 2s」、进行中「Thinking · 6s」、「Ran 4 commands」「Running N commands」「· N failed」、「42 lines」「2 commands」。用户消息、回复正文与其余界面文案保持中文。
- **工具组（Tool Group）**：含 bash/read/grep 的过程列表是一个可折叠卡片，只有一行标题：「› Ran 3 commands · Thought 3s」，可再加「Read N files」「N searches」；右侧状态为红色「N failed」、灰色「N failed · recovered」、蓝色转圈「Running」、灰色「all passed」或「未执行」。失败按每条命令最后一次尝试计数，与行显示一致。失败之后组内还有成功的调用，或这一轮在本组之后继续（有正文或后续回复，不算并入本组的消息），即视为已恢复：灰色、默认收起；只有本轮停在失败上才是红色并默认展开。失败的那一行始终保留 ✗ 和 exit 码。
  - 默认展开：本轮仍在进行这一段（后面还没有正文）、有工具在运行或有未恢复的失败；否则收起。用户点击后以用户选择为准。收起时行仍挂载，跳转、搜索与「pi:reveal-tool」会自动展开并定位。
  - 行：等宽 12.5px、左右 14px、行间无分隔线；✓ 绿 / ✗ 红 / › 灰（思考行「Thought for Ns」）。右侧元信息：失败为「exit N」，成功为实测用时（≥0.1s），否则为行数。失败的行保持单行，点开才显示输出（组本身已因失败展开）。
  - 只有思考、没有工具的列表不加组标题，保持原单行样式。
- 思考行：完成时为「› Thought for Ns」（无实测耗时显示「Thought」，悬停说明耗时未记录），点击在行下展开正文；进行中为转圈 + 蓝色「Thinking · Ns」+ 最新一行斜体灰字单行省略，计时从该行出现开始。
- 连续的 bash 调用合成一组。组标题写「Ran N commands」，有失败时再加「· N failed」，展开箭头靠右。只有 1 条命令时不显示组标题。历史组收起为一行时显示首条命令的摘要，多于 1 条时右侧标「N commands」，不重复上方的叙述句。运行中的命令用转圈代替圆点。
- 每条命令一行：
  - 如果命令带 `echo "=== 标题 ==="`，就用这个标题当名字，后面跟灰色等宽字体的真实命令（单行，超出部分截断）。
  - 可以识别的 `sed -n` 读取，显示文件名和行号范围。
- 去掉开头的 `cd 项目目录 &&` 和结尾的 `2>/dev/null`。展开、复制和重跑都使用完整的原命令。
- 标题相同的连续命令合成一行，标「试了 N 次」，显示最后一次的命令和结果。
- 输出默认收起；工具组之外的命令组里失败的那一条自动展开。输出最多显示 6 行，带行号，用 `--output-bg` 底色。
- 组内只显示最后 8 条，上面显示「展开全部」。
- 工具组行显示 ≥0.1s 的实测用时；其他位置不到 1 秒不显示用时；没有实测数据时显示「耗时未记录」。

### 4.3 文件改动（35a）
- 对话与代码改动遵循 [35a 设计](chat-diff-design.md)。成功改动在每轮汇总卡与独立 ChangesPanel 中显示；失败和运行中的调用保留状态。历史命令组默认收为一行，当前运行组展开。
- 面板默认本轮，支持整个分支与未提交；600px 对话列，面板最小 560px；1200px 以下使用抽屉。
- 以下旧卡片规则只用于失败详情及兼容视图。
- 标题行：操作 · 文件路径 · `+N −M` · 状态。
- diff 在浅色模式下：新增行用 `--green-soft` 底，删除行用 `--red-soft` 底，行号那一栏颜色再深一档。深色模式下用对应的深色变量。
- 相邻 3 次及以上的编辑合成一个文件列表，每个文件的 diff 默认收起。

### 通用工具卡片（#45）
- 自定义/MCP 工具使用紧凑标题行：工具图标、可点击折叠的名称、状态与耗时；放大和复制参数使用带可访问名称的图标按钮。
- 简短标量参数按键值展示，复杂参数保留可滚动原文；输入区明确标为「参数」，输出区保持既有截断与展开行为。
- 完整输出下载位于卡片底部的轻量操作区，不使用突兀的默认按钮。没有文本但有输出文件时说明可下载完整结果，不展示空输出框。
- Bash、文件读取、编辑和 Codemode 专用卡片保持各自布局。窄屏标题允许名称截断，参数自动换行，所有操作可键盘访问。

### 4.4 等待指示器（31a）
- 三个 6×6px 方块（`#EE8C7C` `#3E8FC0` `#F2BC4E`），圆角 1.5px，间距 3px，依次呼吸，周期 1.2s。
- 文字 13px，字重 500，灰色加流光（1.8s）；用时 12px 灰字。
- 位置：最后一个内容下方 8px，左边留 2px。
- 聊天运行状态文案固定使用英文（包括中文界面），计时用 sec/min，等待指示器里的停止链接为 Stop：

| 阶段 | 文案 |
|---|---|
| 刚发出消息 | Understanding your question |
| 工具调用刚结束 | Reading command results / Reading files |
| 有思考但还没有正文 | Thinking |
| 测试或构建命令超过 4 秒 | Waiting for test results / Waiting for build results |
| 插话已送达 | Processing your direction |

- 300ms 后才出现；4 秒后显示用时；60 秒以上显示「M min SS sec · Stop」。
- 收到正文或思考内容时立刻消失。断线、重试、压缩或静默告警时由对应的状态接管。
- 系统开启减少动态效果时，方块和文字都静止。
- **不再使用**：「正在分析请求」「仍在思考」「响应较慢」「等待模型」，以及显示在标题行的蓝色等待状态。

### 4.5 工具调用未执行（33a）
- 完整交互与验收见 [33a 设计说明](tool-unexecuted-design.md)，取代 32a。
- 每次用户请求最多自动提醒一次；同一次异常用稳定 incidentId 关联，真实工具调用后恢复正常。
- 首次漏出调用只留灰色说明；自动提醒显示居中事件行，跳过问题导航、编辑和折叠摘要。
- 最终停住只在最后回复后显示一张白底、浅红标题的恢复卡，原文按尝试次数集中展示。
- 换模型使用可键盘操作的自定义菜单，重发原始问题及其附件。
- 自动提醒中三栏统一黄色工作中；最终停住统一红色中断，无计划时显示说明代替空状态。
- system 消息只显示为分隔线（见 4.1）；回到底部的出现条件见 4.6；上下文与缓存为零时隐藏。

### 4.6 结构化回复（4a）
- 回复里的盒线字符树（`├──` / `└──`，每行都是分支，至少 3 行）渲染为浅色结构化树：顶部「根 · 根标题 · N 个分支」，节点编号用灰色等宽字，副说明灰字，子层用左侧细线缩进。多数节点共有的 `← 本轮` 类标注只在顶部说明一次，各节点只显示与之不同的部分（黄色标签）。用户粘贴的树保持原样。保留复制原文。
- 同一回复里有 2 个及以上 `❓ **Q1** - **标题**：问题` 时，问题渲染为卡片：编号、标题、问题说明；`(a) …;(b) …` 选项逐行可点（单选，再点取消）；`➡️ 推荐 (c)。理由` 的推荐项带「推荐」标记并默认选中，理由显示在选项下。没有字母选项的开放问题，推荐答案作为一个可选项（默认选中）。每张卡片最后都有「其他」行：单选圆点 + 下划线输入框（占位「不采纳以上选项？写下你的答案或原因…」），聚焦或输入即选中；写了内容才计为已答，空内容列入「Qx 待回答」。发送时「其他」按「Qx 标题：其他 · 内容」附上（多行合成一行）。「全部采纳推荐」覆盖所有题的选择，已写的「其他」文字保留，可重新选回。卡片之间的普通段落照常显示。
- 只有最新且已结束的回复可作答。此时输入框上方出现回答栏：「已选 N / M」「Qx 待回答」、「全部采纳推荐」、「发送回答」；占位文字为「补充说明，或直接输入其他回答…」。发送内容为每题一行「Q1 标题：(c) 选项」，输入框里的文字附在最后，走普通发送流程（附件、当前文件、排队规则不变）。
- 「回到底部」是 28px 圆形箭头按钮，放在阅读列右侧留白、输入框上方，不覆盖正文和用户气泡；只在离底部超过一屏且正在向上滚动时出现，不推动输入框。文字放在悬停说明与可访问名称。

## 代码搜索（⌘P）
- 文件栏「搜索文件」与 ⌘P 打开代码搜索弹窗，宽 min(980px, 94vw)；⌘K 全局搜索不变。
- 顶部：搜索图标 · 「代码 / 文件名」分段切换（Tab 切换）· 输入框 · Aa（区分大小写）/ ab（全词）/ .*（正则），选中为 `--accent-soft` 底与 `--accent` 字。第二行「范围」填 glob，逗号分隔（如 `src/**/*.ts, !**/*.test.ts`），右侧「N 处匹配 · M 个文件」。
- 代码模式由服务端 ripgrep 搜索（随应用打包，遵守 .gitignore，字面量默认；单文件 20 条、总 500 条、5 秒、单行 300 字符），300ms 防抖，结果分批流入；新请求立即终止旧进程，关闭弹窗也会终止。正则无效时提示「正则表达式无效」且不发请求。
- 左栏按文件分组：文件名 · 目录 · 匹配数；每行行号 + 片段，命中用 `mark`（`--accent-soft` 底）。右栏预览命中行前 8 行到后 12 行，命中行浅蓝底与左侧色条。
- ↑↓ 选择，Enter 打开文件并滚动到命中行（复用 `pi-harness:open-tool-file`），Esc 关闭。文件名模式保留原交互，服务端改用 `rg --files`（含点文件、跳过 gitignore 目录），ripgrep 不可用时回退到原遍历。
- 窄屏隐藏预览，输入框换到第二行。跳转到定义、查找引用与符号索引尚未实现（指导文档第 2、3 步）。

## 5. 输入框（28a）
- 文件拖放结束、取消或窗口失焦后立即清除窗口遮罩；输入框等子区域独立接收文件时也必须清除。
- 圆角 8px，描边 `oklch(0.88 0.005 80)`。只有聚焦且有内容时，描边才变成 `--accent`，不加外部光晕。
- 底部一行依次是：附件 · 模型 ▾ · 思考 ▾ · 插话/排队 ▾（只在运行中显示）· 上下文 [36px 进度条] N% · ■ 停止 · ↑。缓存命中率放在上下文弹层里；只有缓存数据时触发器才显示缓存。
- 图标按钮 28×28px，圆角 `--r-sm`：
  - ↑ 发送：没有输入时是灰色，不能点；有输入时是 `--accent` 底、白色箭头。
  - ■ 停止：只在运行时显示，是运行中的主按钮（3a）：`--heading` 底、`--bg` 字，方块加「停止」文字，30px 高；悬停变 `--red` 底。运行中输入为空时隐藏发送按钮，有内容时再出现。
- 快捷键：↵ 按选中的方式发送，⌥↵ 用另一种方式，⇧↵ 换行。Esc 在有文字时清空，空输入时停止。
- 待发消息固定在输入框上方，只占一行：黄色标签 · 摘要（超出部分用省略号）· 撤回。
- 宽度不够时：先缩短模型名，输入框 ≤530px 时隐藏缓存摘要，按钮不缩小。

## 6. 右栏
- 普通文件栏与 Wiki 目录统一使用顶部「搜索文件」入口（Cmd/Ctrl+P）、32px 树行、18px 层级缩进及中性线框文件／文件夹图标。同级预留相同的展开箭头位置，名称用界面字体。悬停／键盘聚焦使用暖灰背景，右侧引用按钮为浅黄色底；引用文件或目录只附加路径、不自动发送。触屏持续显示引用入口。
- 目录已删除、无权限或不可读取时，在对应树节点下显示原因和刷新按钮，不弹出重复通知；根目录失效提示重新选择项目。刷新成功清除错误。
- 文件标题栏提供新建文件与刷新按钮；新建在标题下输入工作区相对路径，父目录需已存在，创建空文件后打开，重名报错并保留输入。刷新保留展开状态并更新已展开目录。Wiki 文件栏共用新建入口，默认填入当前文档所在目录。
- 上半部分是文件树，下半部分是「进度 / 输出」两个平铺分区，用细分隔线隔开，不再套卡片（3a）；分区标题 11px 灰色，两区可以分别折叠。空状态只有一行说明文字，紧贴标题，不显示占位图形。
- **进度**：优先显示原生 plan 的步骤；无计划的任务显示按工具步骤归并的阶段行（同一行样式，标题下一行 10px 单行摘要，不虚构计划）；此时分区标题改为「步骤」，右侧灰字「N 步」。每步一行：绿色 ✓（进行中转圈；只有之后再无成功步骤的失败才是红 ×，探索中失败后继续推进的算成功）· 标题（模型的叙述标题原样保留；「读取 2 项」这类通用标题按实际内容改写为「读取 N 个文件 · 运行 M 条命令」）· 右侧用时（≥0.1s）；下方逐行列出涉及的文件或命令（等宽 12px，工作区内用相对路径，短的家目录路径保留 `~/`，其余只显示文件名，同名文件补上一级目录；最多 4 行，其余「还有 N 项」）。点击文件打开预览，点击命令跳到对话中的对应行。本轮已采用计划的当前步骤用 `--accent`；尚未用于本轮的历史计划中，未完成步骤统一显示待办，不高亮或自动滚动到历史当前项。完成用 `--green` ✓，失败或中断用 `--red`。历史计划仅显示「此前未完成计划」，不提示用户确认；计划工具不引入单独的审批步骤。本轮结束但计划未收尾时显示「本轮已结束 · 计划待继续」（issue #63）。
- **输出**：只列当前任务里成功 write/edit 的文件，每个文件显示 `+N −M`。
- 不显示命令记录、读取记录、「计划有变」提示或总耗时。

## 7. Wiki（34a）
- 文件栏提供可聚焦拖动手柄，记忆宽度；方向键以 10px 调整，双击或 Home 恢复默认。窄屏文件抽屉保持固定宽度，手柄隐藏。
- 索引未完整时才显示黄色状态「已索引 N / M · 跳过 K」，数字带千分位；未统计完的总数显示「统计中」，不用 +。原因放悬停提示和详情，详情逐类统计。
- 面包屑只显示项目相对目录，空间不足中间省略、悬停显示完整路径。树行 32px，文件预留箭头宽度，与同级目录名对齐。
- 标题信息到正文 28px，段落间距 .75em；开头连续的字段/值作为可折叠的 12.5px 属性表，保留 Markdown 原文。输入框禁止手动缩放。表格图标带表头，引用图标用左竖线，宽版用横向双箭头。
- 文档页以 [Wiki 文档页 v2](wiki-doc-v2-design.md) 为准：默认直接编辑，独立 44px 插入栏，标准正文 760px、宽版 1000px。H1/H2 使用本地衬线子集；保存状态位于顶栏。
- 明确的 `./`、`../` 文件链接可直接打开未参与后台索引的知识证据；服务端仍校验工作区真实路径，缺失文件显示读取错误，模糊双链继续要求索引中的唯一匹配。
- 已登记知识目录的 evidence 快照在 Wiki 中只读，知识正文继续使用现有编辑与保存流程。
- 工具栏与 `/` 共享全部 11 个插入项，按正文、H2、H3、列表、表格、图片、任务列表、引用、代码块、文档链接、日期排序，全部直接显示，不再使用「＋」菜单；标题按钮分别设置固定级别，窄栏横向滚动；表格 8×6 尺寸格，代码语言含 Mermaid，渲染图表并保留源码。
- 目录选中项使用暖灰底，显示中性线框文件／文件夹图标，不显示蓝色竖条。标题元信息显示日期、阅读时长和标签。
- 表格尺寸格和行内代码分别使用 `--r-wiki-grid`（3px）、`--r-wiki-code`（4px），为文档内容专用令牌。
- 文档正文最宽 760px（宽版 1000px），两侧各 64px 留白；左栏 250px，对话面板 400px。
- Markdown 统一打开可编辑文档弹窗，桌面宽 92vw、最大 1440px、高 90dvh，小屏全屏。顶栏显示文件名、保存状态、放大／还原和关闭。放大只改变尺寸，保留编辑器。后台聊天保持挂载，打开／关闭／切换文档不创建或切换会话。
- 弹窗右侧默认展开 400px Agent Chat，可拖动调宽、收起；小屏以覆盖式面板展示。复用原聊天的消息和输入框实例，关闭弹窗后原位返回。保留草稿、附件和进行中的回复，不新建文档会话；发送前保存文档，保存失败保留输入。选区「问 pi」先保存，再把路径与点击时选中文字追加到右栏输入并聚焦，弹窗保持打开、不自动发送。文件栏默认收起，不显示底部输入胶囊或模式切换。引用按请求 ID 去重，并校验工作区与原会话。
- 关闭、遮罩与 Escape 共用保存保护；失败后可继续编辑或明确放弃。Escape 先处理内部菜单和弹窗。弹窗约束焦点并隔离背景，重开同文档恢复滚动位置。

- Wiki 代码配色跟随应用外观，浅色和深色色板分别在根变量中定义一次；不再使用独立 `data-code-theme` 覆盖。
- 保存状态的圆点用 `--green`；改动提示的图标用 `--green`。
- 停止输入 800ms 后自动保存；选中文字时才显示格式工具条；`/` 打开 300px 宽的单列菜单。

## SSH 节点工作台

节点连接后左侧显示 SSH 终端与文件，右侧显示 Agent Chat，并自动准备使用本机模型配置的隔离会话。无需远端安装 pi 或再次点击启动。准备期间显示状态，输入框常驻；准备完成后即可发送。失败时在右侧显示错误与重试入口，SSH 终端保持可用。正文按用户消息、助手回复、思考与工具结果展示；发送确认后才清空草稿，保留排队/纠正、停止、模型选择及新对话。远端目录在会话准备前或重开时设置，工具明确作用于当前节点；左侧页脚说明共享终端及执行期间的输入锁定。关闭 Agent 后保留重新打开入口，不立即自动重开。

Wiki 插入菜单在输入触发浏览器自动滚动时继续跟随可见光标定位；光标离开视口或窗口改变尺寸时关闭。菜单自身的列表滚动不关闭菜单。

### Wiki 模型选择（#50）

Wiki 弹窗右栏复用原聊天的模型、思考强度选择器及输入框；断线和项目切换期间禁用。

### 节点工作台左右分栏（#48）

节点连接后左侧常驻 SSH 终端与文件，右侧常驻本机 Agent 经 SSH 操作节点的对话；不再通过页签互相隐藏。窄屏改为上下排列，保留两侧可见和独立滚动。连接成功自动准备 Agent；连接本身不安装软件、不调用模型。本地主聊天与各节点对话、工具及历史彼此隔离。

### 文件树参考图版

文件标题栏下提供「搜索文件」入口（Cmd/Ctrl+P），只搜索当前工作区文件；Cmd/Ctrl+K 保留全局搜索。根目录显示加粗项目名，可整体折叠。目录行使用系统无衬线字体、32px 行高、中性线框文件夹图标及每层 18px 缩进；改动目录右侧用浅黄色数量标记。保留新建、刷新、隐藏文件开关、附件操作及下方任务面板；键盘上下移动和左右展开收起包括根节点。

### UI/UX Pro Max 全页优化

范围和验证进度见 [全页面优化与验收](ui-ux-polish.md)。设置在 640px 以下采用顶部带图标与文字的横向导航，内容区占满宽度，选中项有 `aria-current`。弹窗进入时焦点置于可操作控件，Tab/Shift+Tab 留在当前最上层弹窗内，关闭恢复触发入口；按钮保留可见焦点。输入区仍不恢复用户要求去掉的内层蓝框。小屏弹窗输入文字 16px，避免移动浏览器聚焦时自动放大。

Git 工作台在 700px 以下将改动/历史列表放在 diff 上方，各自滚动，避免手机上两列挤压。分支与提交输入保留可访问名称，错误使用 alert。触屏终端工具按钮、Git 行及节点主要操作最小 44px；手机表单输入 16px，长路径可换行。

手机文档弹窗支持切换正文与原聊天；桌面右栏默认展开聊天。手机文档正文为 16px，标题 28px，左右留白 20px。

### Secondary dialogs and previews

Node source/credential/edit forms, session-tree navigation/bookmark/content dialogs, and provider authentication use the shared focus boundary. Conditional dialogs register only while visible; reopening captures the new trigger. Escape in provider authentication closes only that topmost dialog, leaving settings underneath open. Small-screen secondary dialog fields use 16px text; action rows wrap and touch targets have at least 44px height. SQLite tables retain their own horizontal scrolling.

扩展安装/确认、单文件编辑与 MCP 原始 JSON 编辑使用共享弹窗焦点栈；Tab 和 Shift+Tab 仅在最上层弹窗循环，关闭后恢复触发入口，保留原有保存及草稿丢弃确认。

Wiki 搜索、离开确认和阅读信息弹窗使用共享焦点栈；弹窗首次绘制前完成焦点转移，避免打开后立即按 Escape 丢失操作。扩展内联请求保持非模态，输入控件具有名称；媒体只读预览不显示“已保存”状态。

## 数据库工作台

顶栏「数据库」打开 92vw（最大 1440px）、90dvh 的弹窗，小屏全屏。左侧连接／库／Schema／表树采用文件树线框图标和搜索，中间数据、结构和 SQL 页签，右侧复用当前 Agent Chat。文档与数据库弹窗互斥，关闭保留草稿、附件与原聊天位置。连接表单使用 driver、host、port、user、password、db_name，支持 TLS。来源扫描发生在服务所在机器，上传发生在浏览器；导入预览后手动同步，密码缺失需补填。第一版只读；问 pi 追加引用不发送，发送时仅对当前会话开放所附加连接，授权可撤销。查询有取消、超时和截断提示。

## 13. 节点工作台（5a）与回复配色（4a）

- 节点连接信息、节点切换和断开合并为一行；终端标签留在终端内部。左侧手动终端与 Agent 的 remote_command 共用 SSH PTY，执行期间锁定普通输入，Ctrl+C 可中断；结果卡显示实际命令、行数和状态，可跳转到终端对应记录。
- 只读命令直接执行；写入、系统状态变更及无法可靠判定的命令先在 Agent 面板确认。允许或拒绝只影响当前请求；用户可显式授权本次节点 Agent 会话内同一命令族，重连或新对话清除授权。remote_write 同样必须确认。
- 登录欢迎信息默认折叠，更新和重启提示保留；可以展开查看完整信息。Agent 使用头像 + pi 名称，表格表头与内容左对齐并有分隔线；输入框去掉内层边框，模型选择放在底部自定义菜单。
- 4a 问题选中项使用中性深色描边与白色面板底色（深色主题使用对应令牌），推荐标记是浅灰描边标签；题号、树分支字母为灰色，回答主按钮用墨色。正文链接和当前页签保留蓝色。
