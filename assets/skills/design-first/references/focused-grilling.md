# Consequential questions
Resolve code facts by inspection. Ask the user about product intent, unacceptable tradeoffs or consequential uncertainty.
Quick normally needs zero or one question group; Standard normally at most three. These are attention budgets, not permission to ignore critical unknowns.
Make reversible implementation choices and record assumptions. For blockers record originating stage, reason, exit condition and next independent work.
Use existing answers when their assumptions still hold. A repeated question with changed assumptions needs renewed judgment.
