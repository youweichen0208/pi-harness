---

Use the Small feature route of the bundled Design First skill. Read its instructions in the [Design First workflow](../SKILL.md), then the [small-change guide](../references/small-changes.md). Use the current session and model. Align the requested behavior, compatibility boundary, acceptance and spec delta for confirmation, then use native tools to implement, test and record the spec disposition. This skill selects the route and does not authorize implementation by itself; after the saved proposal is presented, use only current-session authorization for that exact design and spec impact. Keep local changes Quick; expand only when the observed impact warrants it.

If the request is empty, ask what behavior the user wants before investigating or changing files.
