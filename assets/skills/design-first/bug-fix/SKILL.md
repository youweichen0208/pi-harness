name: bug-fix
description: Diagnose and fix a bug, run regression checks, and reconcile its spec
---

Use the Bug fix route of the bundled Design First skill. Read its instructions in the [Design First workflow](../SKILL.md), then the [small-change guide](../references/small-changes.md). Use the current session and model. Start with reproduction and expected/actual behavior, present the supported diagnosis and proposed fix for confirmation, then use native tools to implement, test and record the spec disposition. This skill selects the route and does not authorize implementation by itself; after the saved proposal is presented, use only current-session authorization for that exact design and spec impact. Keep local changes Quick; expand only when the observed impact warrants it.

If the report is empty, ask for the observed problem and expected behavior before investigating or changing files.
