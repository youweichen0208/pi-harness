# Outcome

## Acceptance coverage
Map requirements to implementation and evidence. Distinguish implemented from verified.

## Actual verification
Record commands, times, inputs, environment, exit codes and limitations. Clearly label checks not run.

## Deviations and remaining work
Explain material differences, unresolved risks and the next action.

## Durable documentation
Record spec synchronization as updated, unchanged (with reason) or pending (with next action), linking the affected path/section and change evidence. Link reviewed glossary/ADR updates and publication results where applicable.
